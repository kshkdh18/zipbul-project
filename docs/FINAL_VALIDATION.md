# 최종 제출 검증 — 2026-10-09

## 통합 범위

`origin/main`의 Zipscan·Zipcontrol과 로컬 Zipbul 메인 앱을 병합했다. 메인 앱 소스와 잠금 파일, 배포 어댑터, 제품 문서를 저장소에 포함했다. 공통 Python용 `lib/` 제외 규칙이 메인 앱의 필수 소스를 누락시키던 문제를 `zipbul/.gitignore`에서 수정했다.

기존 기획 문서와 해커톤 준수 지침을 보존하고, 팀원이 추가한 컨트롤러 설명을 반영했다. 원본 촬영 데이터·준비된 현장·API 키·빌드 결과·발표자료 임시 산출물은 Git에 포함하지 않는다.

동시에 진행되던 Sites 배포 작업이 완료된 뒤 version 4의 최신 어댑터·업로드 처리·분석 이력·동기화·배포 기록까지 포함했다. 별도 디렉터리에서 검사한 코드의 SHA-256과 최종 작업 트리의 코드가 일치함을 확인했다. Sites의 두 현장과 68개 자산 검증, 업로드 처리 서버 의존성과 검증 범위는 [Sites 배포 기록](../zipbul/sites/README.md)에 정리되어 있다.

## 이번 통합에서 직접 확인한 결과

| 대상 | 검증 | 결과 |
| --- | --- | --- |
| 메인 앱 | Git에 기록한 파일만 별도 디렉터리로 내보낸 뒤 `npm ci`·프로덕션 빌드·타입 검사 | 통과 |
| 메인 앱 | `npm test` | 로컬 6개 + 클라우드 어댑터 6개, 총 12개 통과 |
| 메인 앱 | `npm run test:browser` | 실제 입력의 복제 현장, 합성 업로드, 충돌·경로 검증 모두 통과 |
| 컨트롤러 | `uv run --frozen pytest -q` | 143개 통과 |
| 컨트롤러 | `uv run --frozen ruff check src tests tools android/build.py` | 통과 |
| 스캐너 텍스처 | `uv run --frozen pytest -q` | 9개 통과 |
| 스캐너 Core | `swift test` | 이 Mac의 Swift PackageDescription 링크 오류로 시험 시작 전 중단 |

브라우저에서는 수동 위치 연결과 검토 저장·새로고침 보존, 검토 revision 충돌 거부, 3D 관계도 27개/집중 보기 5개 노드와 2D 전환, 원본 영상 Range 응답, 약 0.60m의 접지 이동과 Escape 정지를 확인했다. 별도 합성 입력에서는 GLB+영상 업로드·메타데이터 없는 수동 점검, 벽 충돌, 막힌 경로 거부, 보정 구간 근거 보존과 보정 삭제 후 경로 무효화를 확인했다. 브라우저 페이지 오류는 없었고 테스트용 현장은 종료 후 제거했다.

제출 검증 과정에서 클라우드 API 테스트의 로컬 `output/sites-transfer.json` 의존성을 합성 데이터로 대체했다. 최신 3D 관계도와 촬영 시점 이동을 검사하도록 기존 브라우저 테스트를 갱신했으며, `npm test`에 클라우드 테스트도 포함했다.

## 공개 서비스와 검증 한계

https://zipbul.summit1123.co.kr 의 홈·상태 응답과 두 현장 조회, 현장별 GLB·원본 GLB·영상의 100바이트 Range 응답을 확인했다. 공개 주소의 실제 Chromium에서도 두 현장 3D 로딩·공간 전환·점검 항목·3D 관계도 노드 수를 확인했고 페이지 오류는 없었다. 앱 API 변경 요청이나 모델 호출 없이 조회했다. Mac 터널 배포 구성과 운영 조건은 [메인 앱 README](../zipbul/README.md#mac-터널-배포)에 있다.

현장 02의 표시용 GLB는 약 159MiB다. 첫 공개 브라우저 검사에서 120초 로딩 제한 시간을 넘겼고, 후속 검사에서는 장면이 로딩되어 확인을 마쳤다. 초기 로딩 속도는 네트워크와 기기에 영향을 받으므로 시연 전에 두 현장을 열어두고 로딩 완료를 확인한다. 로컬 기능 시험 통과를 공개 네트워크의 로딩 시간 보장으로 해석하지 않는다.

이번 통합 검사에서는 새 유료 모델 호출이나 실제 Android 조이스틱 입력, iPhone LiDAR 수집을 실행하지 않았다. AI 관련 단위 테스트는 모의 응답을 사용한다. 스캐너의 종전 실기기 검증과 남은 항목은 [스캐너 검증 기록](../zipscan/docs/verification.md), 컨트롤러는 [검증 기록](../zipcontrol/VALIDATION.md)을 참고한다. 종전 기록을 이번 Mac에서 재검증한 결과로 간주하지 않는다.

현재 Mac에는 Xcode 앱이 없고 `/Library/Developer/CommandLineTools`의 Swift 6.0.3이 선택되어 있다. `PackageDescription.Package` 생성자 심벌을 찾지 못해 `swift test`가 시작되지 않았다. 이 결과는 스캐너 시험 통과를 뜻하지 않으며, 호환되는 Xcode 환경에서 추가 확인해야 한다.

새로 받은 저장소의 메인 앱은 준비된 현장을 포함하지 않는다. 실행 후 GLB·영상을 가져오거나 별도로 전달받은 입력을 등록해야 한다. 모델 표본 분석과 시뮬레이션 이동 검증은 실제 현장의 안전 판정 또는 전체 위험 탐지 성능 검증이 아니다.

자동 검사 결과와 캡처는 로컬 `zipbul/output/`와 `zipbul/output/submission/`에 남긴다. 원본과 개인정보가 포함될 수 있는 결과 파일을 소스 저장소에 추가하지 않는다.
