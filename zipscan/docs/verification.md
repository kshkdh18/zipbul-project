## 실제 수집 결과

15초 시험을 두 번 진행했다. 첫 시험에서 1920×1440 H.264 450프레임, 깊이 150개, 메쉬 78,373면이 저장됐고 수집 누락은 없었다. 검증에서 발견한 두 문제를 수정했다.

1. AVAssetReader의 0 sample 경계 버퍼를 영상 프레임으로 세던 오류.
2. MP4 기본 time scale 600에서 AR 시각이 양자화되는 문제. 영상 트랙을 1,000,000으로 명시했고, 비균등 PTS로 회귀 시험을 추가했다.

수정 후 한국시간 11:29에 진행한 15초 시험은 다음을 통과했다.

이 결과는 **짧은 실기기 수집의 관측값**이다. 10분 안정성이나 공간 측정 정확도를 증명하지 않는다. 촬영 데이터·스크린샷·xcresult는 로컬 `artifacts/` 또는 `/tmp`에만 두고 Git에 포함하지 않는다.

- Swift Package: 10분 샘플링 드리프트, 행렬과 OBJ 좌표, 행 패딩 제거·깊이 K, 타임스탬프 파일명, 잘린 JSONL, 실제 MP4 PTS와 패키지/ZIP 재검증, 바이너리 범위/신뢰도 누락, 거짓 PTS, 메쉬 누락, 중단 복구.
- iOS Recorder: 정상 녹화, 깊이 누락 시 partial 유지, 저장 경로 장애, 중복 종료 방지.

- 실기기 UI: 15초 자동 수집 → complete → ZIP 내보내기.

## 남은 실기기 시험

사용자 요청에 따라 **10분 이동 시험은 나중에 직접 진행**한다. 기본 30fps/10Hz가 시연용으로 최종 검증되었다고 표시하지 않는다.

1. 일반 실행으로 새 스캔을 시작한다. Debug 자동 촬영 인수 없이 기본 상한 600초를 사용한다.
2. 방과 짧은 복도를 천천히 이동한다. 발열·추적·깊이 표시를 확인한다.
3. 10분 자동 종료 후 complete 여부, 영상/깊이 누락, 메쉬와 영상 재생을 확인한다.
4. ZIP을 Mac으로 가져와 `swift run zipscan-validate <해제 폴더>`를 실행한다.
5. 실패하면 다음 시험에서 깊이 5Hz, 이후 영상 15fps 순으로 낮춘다. 통과한 설정만 시연 기본값으로 채택한다.

실제 기기의 강제 종료·전화/AR 중단·권한 거부·디스크 고갈·critical 발열 상황은 별도 수동 확인이 필요하다. 자동 시험의 모의 저장 장애와 복구 검증을 해당 실기기 상황의 통과로 간주하지 않는다. RGB/깊이의 실제 장면 대응과 공간 좌표의 수치 정확도도 현장 기준물을 사용한 추가 검증 대상이다.
